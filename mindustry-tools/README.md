# Mindustry Tools

One desktop mod combining Auto-drill, Surge routing, Solar-pack, Battery-pack, Wall-pack, Mine-pack, and Mega Priority for Mindustry Steam 160.7.

## Install

Download `mindustry-tools.jar` from the [latest release](https://github.com/Aaronik/Mindustry-mods/releases/latest). **Remove or disable the old standalone mods first** (`auto-drill-routers.jar`, `solar-pack.jar`, `battery-pack.jar`, `wall-pack.jar`, `mega-priority.jar`) or you'll get duplicate controls and input handlers. Then import the JAR from Mindustry's Mods screen or copy it to the game's `mods` directory. Fully quit and restart Mindustry before using it. On the Steam macOS install used for testing, mods are stored at:

```text
~/Library/Application Support/Steam/steamapps/common/Mindustry/Mindustry.app/Contents/Resources/saves/mods/
```

If building locally on that machine, `./install.sh` compiles, verifies the JAR, moves standalone JARs into `mods/legacy-mindustry-mods-backup/`, and installs the combined JAR atomically. Set `MINDUSTRY_JAR=/path/to/desktop.jar` or `MINDUSTRY_MODS=/path/to/mods` if needed. The local workflow installs even while Mindustry is running, using atomic replacement rather than writing in place. Fully restart afterward to load changes; this is not hot reload. If the current session encounters class-loading errors, restart it.

## Use

**Power readout:** Passive panel anchored beside the live core resource display, falling back to the left/below when needed. One line per distinct player-team power graph in the current map (including isolated/unpowered groups), ordered by building count. Exactly one line per network shows only Net power per second and Battery stored/capacity, without a header, network numbers, building counts, generation/demand breakdown, or coordinates. Hovering a row shows bright yellow pulsing fills and thick black/yellow/white outlines on its on-screen friendly buildings, including nodes. Outline thickness/minimum marker size scale with zoom, and the gentle pulse uses real time rather than accelerated simulation time; leaving the row clears them immediately. Clicking does not latch selection or move the camera. Existing row actors survive stat refreshes to keep hover feedback stable. Omits inert/node-only graphs with no producers, consumers, or batteries, but retains real disconnected consumers even when idle. Uses the same scaled rate basis as vanilla power statistics, so speed presets do not inflate the displayed per-game-second rate. Green surplus/red deficit; scroll to see all groups if necessary. The panel releases only its own scroll focus when the pointer leaves or the panel hides, so map zoom is not left blocked and other dialogs retain their focus. Refreshes every 0.5 real seconds; graph IDs can change with reconnections. No enemy networks and no cross-sector aggregation. Hides with resources/HUD/dialogs. Live layout still needs in-game verification.

**Enemy hover info:** Always-on, passive tooltip—no button. Hover a visible enemy unit/building to see name/team, current/max health and percentage, armor, unit shields when present, range in tiles for units/turrets, turret ammo readiness/type, and powered-building power satisfaction. Units take priority over buildings underneath. It is click-through, draws above HUD buttons, and stays within the screen edges. It hides over UI/dialogs and excludes friendly, derelict, and currently fog-hidden targets (including previously discovered structures outside current vision). Hovered enemy turrets draw a vanilla-style dashed team-colored range circle using their current weapon range, with the same fog/UI checks as the tooltip; buildings without turret range do not draw one. No hidden-enemy reveal. Live HUD behavior still needs in-game verification.

The **2 / 5 / 100** speed row, **Auto-wave**, **Sectors**, **Redir pads**, **Clear props**, **Unit HP**, **Mega priority**, **Surge**, and **Pack** (top to bottom) are always visible just left of the build/command menu, following its live width. **Pack** is the bottom button, the only submenu, and starts closed; click it to reveal **Wall**, **Battery**, **Solar**, **Mine**, **Water**, and **Drill** in a single row to its left, aligned with Pack, without moving the main buttons. Click Pack again to close it. An active tool is highlighted. Choosing a different construction tool disarms the previous one. Closing Pack does not cancel an armed tool; reopen it and click that tool again to cancel.

* **2 / 5 / 100:** Experimental simulation-speed presets for local single-player only (including no hosted multiplayer). The three adjacent buttons have no “x” and occupy the old speed button's exact 175×45 UI-unit area and position, with widths 45/45/85 and no gaps. Only the selected speed is highlighted. Click another to switch directly; click the selected speed to restore normal speed (all unhighlighted). Defaults off and resets on map load/reset, leaving the game, or network entry. Pause still works, and delta is restored after each simulation update so UI timing remains normal. Enemies, waves, and time-based production accelerate together. Per-frame update limits prevent a guarantee of exactly 100× throughput, and large steps may cause combat/movement inaccuracies. Back up important saves first. This does not fast-forward the entire offline campaign clock. Live gameplay still needs verification.
* **Auto-wave:** Toggle on to send the next wave as soon as the vanilla wave button is available: waves enabled, sending allowed, no remaining enemies or active spawn, and permission to send. It uses the same skip-wave action, waits at least one second between requests, and resets to off when a new map loads. It does not bypass the server’s wave controls.
* **Sectors:** Read-only browser of owned bases on the current planet, defaulting to highest recorded total exports/min. Search names/IDs; choose an exported item to rank by that item, toggle name sorting, or Refresh. Zero-export bases stay listed. Rows show sector name/number, total export rate, a complete breakdown of every exported item's icon/name/rate per minute (highest first), destination, and under-attack/current-sector markers. An item filter changes ranking and adds its rate beside the total without hiding the other items. Clicking a row opens the planet map centered on and selecting the sector; it never launches or loads the sector or redirects exports. Rates use campaign export means (items/second converted to items/minute), may be stale, and are not sustainable throughput guarantees. Local campaign only; multiplayer clients are excluded. Dialog layout/navigation still needs live in-game verification.
* **Redir pads:** In a local campaign sector, click once to redirect every other sector on the current planet that has a base and nonzero exports, regardless of item. The mod saves changed sector destinations and refreshes the local import-rate cache. It leaves sectors already exporting here alone. Multiplayer clients and legacy launch-pad campaigns are excluded. Unlike the built-in Landing Pad redirect, no item selection or per-item repetition is required.
* **Clear props:** Click to scan the entire map and queue normal removal plans for breakable auto-replaceable natural props. Buildings, black/static walls, and already queued construction footprints are skipped. Up to 10,000 new removal plans per run, queued in batches; click again while scanning to stop adding plans. Previously queued removals are not undone.
* **Drill (Pack submenu):** Select a drill first (defaults to unlocked pneumatic drill), arm it, then click an ore patch. Queues drills plus a connected router border.
* **Surge:** Click Surge and then a map destination. It searches incrementally across the map (including routes thousands of tiles long) and queues a long-range linked chain of 2×2 Surge Towers. The route stops at the first connectable existing power source it encounters from your destination, rather than adding towers past an already powered node. If that source is a Surge Tower, the first new tower touches its destination-facing side when reachable (adjacency works even if its laser links are full). If it is a friendly power node, solar panel, or battery, the first new tower may start up to about 38 tiles away with a laser link; subsequent towers typically use long-range hops. Valid placements beside black/static map terrain are strongly preferred: a longer wall-hugging route can beat a shorter open-field one, but walls are not required. Redundant intermediate towers are removed when their neighbors can directly laser-link; genuine wall-hugging detours may remain. Insulated buildings that block laser links are avoided. It never replaces buildings or queued plans, and allows removable map props. When both endpoints are constructed, the mod requests links to the predecessor even if builders finish out of order (except the first adjacency connection to an existing Surge Tower); it does not connect to other power-block types. Very long routes may take several seconds to plan; plans appear when the search finishes. Click Surge again while a search is running to cancel it. Builders must still reach and construct the queued towers.
* **Solar-pack:** Arm, then drag a rectangle. Queues large solar panels, filling remaining legal tiles with small batteries.
* **Battery-pack:** Arm, then drag a rectangle. Queues large batteries, filling gaps with small batteries.
* **Wall-pack:** Select either size of wall for the material (defaults to copper), arm, then drag up to a 200×200-tile rectangle. Queues large walls followed by small-wall infill; a fully open 200×200 selection queues 10,000 large walls.
* **Mine:** Arm and drag a rectangle. Queues 1×1 Shock Mines on every valid tile (up to 60 tiles per side and 2,500 tiles per drag).
* **Water:** Arm and click a water tile. Scans up to 1,024 connected water tiles and queues 1×1 Mechanical Pumps with a connected border of 1×1 Liquid Routers, including lanes for interior pumps. It tries horizontal and vertical repeating two-pump-row / one-router-row strips, so a router lane serves pumps on both sides; irregular patches and obstacles may prevent an exact ratio. Auto-drill spacing is unchanged. No conveyors or conduits are added. Unbuildable terrain and existing/queued structures remain protected; removable natural props may be replaced. As with Auto-drill, not every water tile is necessarily covered. The Pack row may be wider than the available HUD space on narrow screens.
* **Unit HP:** Opt-in health and shield bars above on-screen friendly and enemy units, including the player unit. Respects current fog visibility; no hidden-enemy reveal. Click again to hide; defaults off and resets on world load/reset. Health and shields have separate bars; force-field shields use their ability capacity. Externally granted shields have no universal capacity field, so their bars use the highest shield value observed while visible. Depleted/broken shields remain empty once their capacity is known. Hidden HUD/dialogs suppress bars. Read-only; live rendering still needs in-game verification.
* **Mega priority:** Select friendly Megas in command mode, then toggle. Uses vanilla Rebuild → Repair → Mine commands based on available work. Selecting a vanilla command opts those Megas out.

All six Pack modes may build over natural props that the game automatically replaces; buildings and your queued plans are not overwritten. Construction modes queue normal build plans. The mod is quiet on successful actions/cancellation; invalid actions show toasts. Mega Priority is opt-in and resets on world load.

## Build/test

Run `./build.sh` with Java 17+ and a Mindustry 160.7 desktop JAR. It compiles and runs all planner/priority suites, including deterministic Surge route fixtures for map edges, cliffs, removable props, buildings, insulated links, competing sources, blocked destinations, long routes, and seeded irregular maps. These are synthetic map-like fixtures, not actual save files. Combined UI and live construction/power-link synchronization still need in-game verification.
